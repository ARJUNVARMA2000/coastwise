Model check

A random forest predicts each structure's score after training only on the other structures. If it can't beat “always guess the median”, the importances below are weak evidence.

Grouped permutation importance

Bar length is how much worse the held-out predictions get (mean absolute error, score points) when that group's values are shuffled. Larger positive values indicate greater reliance by the analysis model. Values near zero or negative show little evidence of a contribution.

One feature at a time
